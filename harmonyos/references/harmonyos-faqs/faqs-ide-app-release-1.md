**问题现象**

打开上传软件包界面后，提示”No app with the specified package name is found under the team.”。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/37/v3/kgEjXNFkRtyusFJ8BKvNlg/zh-cn_image_0000002654798193.png?HW-CC-KV=V1&HW-CC-Date=20261112T233212Z&HW-CC-Expire=31536000000&HW-CC-Sign=95EC8B1F87D2D1C9CB1C17CCD54EF45726ECCAAF635FB13EF7250A56661AF44F)

**解决措施**

因为当前账号在HarmonyOS 开发者中心没有对应包名的应用，请在HarmonyOS 开发者中心登录当前账号后[创建应用](../app/agc-help-createapp-0000001146718717.md)，再重新打开上传软件包界面。
