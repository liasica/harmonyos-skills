## 问题现象

在[场景化性能测试](../harmonyos-guides/performance-testing.md#section8642101711299)脚本中右键“执行hypium用例”，出现测试资源加载异常[01100]：'NoneType' object has no attribute 'replace'报错。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/57/v3/ZJRxbUN5TCy1qClcbcQCcg/zh-cn_image_0000002631135614.png "点击放大")

## 解决方案

点击工程中的main.py脚本，右键执行Run 'main'进行调试。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/S4HPcgSlRTyy272JVf-myA/zh-cn_image_0000002631295566.png "点击放大")
