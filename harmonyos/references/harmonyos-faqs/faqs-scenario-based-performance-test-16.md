## 问题现象

在[场景化性能测试](../harmonyos-guides/performance-testing.md#section8642101711299)脚本中右键“执行hypium用例”，出现测试资源加载异常[01100]：'NoneType' object has no attribute 'replace'报错。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/23/v3/vZ7UVdVkSBuH8k4vQ53TOQ/zh-cn_image_0000002631135614.png?HW-CC-KV=V1&HW-CC-Date=20261112T233218Z&HW-CC-Expire=31536000000&HW-CC-Sign=10B8966E49B877E2508BA6C27A90742A3F1EB408A633F351EA069B548F71EE38 "点击放大")

## 解决方案

点击工程中的main.py脚本，右键执行Run 'main'进行调试。
