1、可以将公钥转换为十六进制或Base64格式进行存储。

2、获取公钥后，将其转换为数组。

3、将转换后的数组转换为公钥对象。

参考代码如下：

```typescript

import { cryptoFramework } from '@kit.CryptoArchitectureKit'

@Entry

  build() {
    Row() {

          let publicKeys =
```
