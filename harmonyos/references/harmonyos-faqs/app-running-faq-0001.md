**Q：Windows x86模拟器三方C/C++库使用限制是什么？**

**A**：x86模拟器支持已x86化的C/C++三方库调试运行，未x86化的三方库开发者可以参考[tpc\_c\_cplusplus](https://gitcode.com/openharmony-sig/tpc_c_cplusplus)。目前已经x86化的三方库如下：

| 三方库 | 备注 |
| --- | --- |
| MMKV | 自2.0.4-rc.4版本开始支持x86编译。 |
| ImageKnife | 自2.1.1版本开始支持x86编译。请重新安装imageknife再进行编译。 |
| ohos\_videocompressor | 自1.0.3版本开始支持x86编译。 |
| ohos\_coap | 自2.0.5版本开始支持x86编译。 |
| Unrar | 自2.0.2版本开始支持x86编译。 |
| commons-compress | 自2.0.2-rc.0版本开始支持x86编译。 |
| Smack | 自2.0.1-rc.0版本开始支持x86编译。 |
| ijkplayer | 自2.0.3-rc.0版本开始支持x86编译。 |
| ohos\_mqtt | 自2.0.5版本开始支持x86编译。 |
| Mars | 自2.0.1-rc.1版本开始支持x86编译。 |
| mp4parser | 自2.0.2-rc.0版本开始支持x86编译。 |
