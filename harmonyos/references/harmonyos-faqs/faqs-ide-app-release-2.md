## 问题现象

直接用DevEco Studio上传软件包（Upload product）时报错：The build configuration of the current Build Mode cannot be uploaded，如图

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7f/v3/E1gaYoVlRVuw11b33hWKtA/zh-cn_image_0000002658808915.png "点击放大")

## 解决方案

使用DevEco Studio上传软件包（Upload Product）时，需要确保Build Mode是release。操作步骤如下：

1. 点击DevEco Studio上方菜单栏“Select Product”按钮。
2. Build Mode切换为release。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/16/v3/bl3KBT7jR4-uNy8GfJEN9w/zh-cn_image_0000002628569546.png "点击放大")
