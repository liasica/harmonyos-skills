## 应用内滑动页面白块率

|  |  |
| --- | --- |
| **描述** | 应用或元服务的应用内滑动过程白块率应≤ 6.1 ms/s。 |
| **类型** | 规则 |
| **适用设备** | 手机，平板，PC/2in1，智慧屏，车机 |
| **应用形态适用性** | 鸿蒙应用，鸿蒙元服务 |
| **说明** | [本地自测试：DevEco Testing 性能测试](performance-testing.md) |
