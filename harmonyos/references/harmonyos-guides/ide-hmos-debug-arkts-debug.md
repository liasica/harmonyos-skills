可以按照以下方式启动调试会话。

1. 如果需要设置断点调试，找到需要暂停的代码片段，单击该代码行的左侧边栏。设置断点后，调试能够在正确的断点处中断，并高亮显示该行。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8d/v3/8dNPkgd4SKqhgVpa2LjoBg/zh-cn_image_0000002781471130.png?HW-CC-KV=V1&HW-CC-Date=20261114T004727Z&HW-CC-Expire=31536000000&HW-CC-Sign=8F4838575A29110B655BF430B68A2C3C85ECEA57FBCF0805E5F249E9666C31E5)
2. 在设备选择框中，选择调试的设备。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/af/v3/E6bNwRnlRuWhabTagdfLcw/zh-cn_image_0000002781311198.png?HW-CC-KV=V1&HW-CC-Date=20261114T004727Z&HW-CC-Expire=31536000000&HW-CC-Sign=390ADC860B9D386793791CAE9EE8899349BB411757831B1084C27FE28A397DF7)
3. 选择启动调试的配置，在模块选择框中选择需要调试的模块。也可以[配置调试参数](ide-hmos-run-debug-configurations.md)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/81/v3/dDLBEoGqSoenuj56zAJphw/zh-cn_image_0000002810630685.png?HW-CC-KV=V1&HW-CC-Date=20261114T004727Z&HW-CC-Expire=31536000000&HW-CC-Sign=EB7A0392925F94BF4438550A61AFC2FEBC514210ED3D10B0D6B61229DA6427E6)
4. 在工具栏中，单击调试 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c9/v3/v5wWwIiGQgesngP_VTyPHA/zh-cn_image_0000002810630687.png?HW-CC-KV=V1&HW-CC-Date=20261114T004727Z&HW-CC-Expire=31536000000&HW-CC-Sign=178D19765D01ED6948CF38C82E52E6FFD1D96A01C265AFC6E36417CC061F4BE0)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/38/v3/_aAGWNwmTu2XgaBKs9-H_w/zh-cn_image_0000002810750791.png?HW-CC-KV=V1&HW-CC-Date=20261114T004727Z&HW-CC-Expire=31536000000&HW-CC-Sign=A0994884EF1F923208EC92C0A24DADBEF48EA470875AD5989D9E6E9DAB5E724F)
5. 启动调试后，开发者可以通过[调试器](ide-hmos-debug-arkts-debugger.md)进行代码调试。

   如有断点会在断点处高亮，并展示当前断点处的帧和变量。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/88/v3/ttgXU8TdTqyZb19SlA-cug/zh-cn_image_0000002781471134.png?HW-CC-KV=V1&HW-CC-Date=20261114T004727Z&HW-CC-Expire=31536000000&HW-CC-Sign=0B491FE4BEB1A8EBF6405D5F1E754244B27A5E5DEAF8C56B1D1FC311372D76AC)
