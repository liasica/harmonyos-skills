可以按照以下方式启动调试会话。

1. 如果需要设置断点调试，找到需要暂停的代码片段，单击该代码行的左侧边栏。设置断点后，调试能够在正确的断点处中断，并高亮显示该行。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ba/v3/8c8jbXRGQR6IkcqhUcaXWA/zh-cn_image_0000002779608673.png)
2. 在设备选择框中，选择调试的设备。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/fc/v3/jmiSNRq3Rc-TfFzIKnV1cg/zh-cn_image_0000002750169650.png)
3. 选择启动调试的配置，在模块选择框中选择需要调试的模块。也可以[配置调试参数](ide-hmos-run-debug-configurations.md)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a4/v3/q43gcXgMT0y3u7cOuavaZQ/zh-cn_image_0000002779608675.png)
4. 在工具栏中，单击调试 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/62/v3/SBSnSuKEQpqa6gQR9HAICg/zh-cn_image_0000002750009764.png)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/25/v3/olx-wVk6SuGgcJQT7QbzfQ/zh-cn_image_0000002750009762.png)
5. 启动调试后，开发者可以通过[调试器](ide-hmos-debug-arkts-debugger.md)进行代码调试。

   如有断点会在断点处高亮，并展示当前断点处的帧和变量。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/de/v3/9vyo6HdCR2KGl6HSu6v9rw/zh-cn_image_0000002750169652.png)
