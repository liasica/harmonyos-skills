可以按照以下方式启动调试会话。

1. 如果需要设置断点调试，找到需要暂停的代码片段，单击该代码行的左侧边栏。设置断点后，调试能够在正确的断点处中断，并高亮显示该行。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/da/v3/6QiMfAGTSh6HuA5in6DhGg/zh-cn_image_0000002820680993.png?HW-CC-KV=V1&HW-CC-Date=20261124T044245Z&HW-CC-Expire=31536000000&HW-CC-Sign=BAAD41BA5575BEEA40B03FF8A6CE8FD762192DCAB61A828EE15EA513FE3ACB72)
2. 在设备选择框中，选择调试的设备。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4d/v3/zFuk_r1ER1S6BBRO858eFA/zh-cn_image_0000002820680991.png?HW-CC-KV=V1&HW-CC-Date=20261124T044245Z&HW-CC-Expire=31536000000&HW-CC-Sign=B0E87B1D7ED1797460426B2A5C7018A2E54FD07284B123964B6CAB95823A89A5)
3. 选择启动调试的配置，在模块选择框中选择需要调试的模块。也可以[配置调试参数](ide-hmos-run-debug-configurations.md)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/21/v3/80ysjrhFRG-JXL91tIOk-g/zh-cn_image_0000002820680989.png?HW-CC-KV=V1&HW-CC-Date=20261124T044245Z&HW-CC-Expire=31536000000&HW-CC-Sign=FB5D80090D9AEAF9F1B69EDD580DA79068F4745DEA5ED2A17DFAA1E058381C3B)
4. 在工具栏中，单击调试 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4b/v3/vi5BusAzSD-rYUMgfZ9pJg/zh-cn_image_0000002791841058.png?HW-CC-KV=V1&HW-CC-Date=20261124T044245Z&HW-CC-Expire=31536000000&HW-CC-Sign=52DE9A32A8B918FB09A2B27FF70020D8B2D964A6961E86252D4F4D1419AB14D5)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/67/v3/L19J5tpaSNaNkxYIeynEpA/zh-cn_image_0000002791841056.png?HW-CC-KV=V1&HW-CC-Date=20261124T044245Z&HW-CC-Expire=31536000000&HW-CC-Sign=3AE48C7DE3C09C63B15C1845BF4847EC33A5CC495DF5EAC33263832A3717E9E8)
5. 启动调试后，开发者可以通过[调试器](ide-hmos-debug-arkts-debugger.md)进行代码调试。

   如有断点会在断点处高亮，并展示当前断点处的帧和变量。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/50/v3/nsP8-nEYSTKiugogRxZwEg/zh-cn_image_0000002791841054.png?HW-CC-KV=V1&HW-CC-Date=20261124T044245Z&HW-CC-Expire=31536000000&HW-CC-Sign=FD329291DE07BA9A8266EA0E64D9D9C803AC1D7916507B528EDDAFEF73C20A62)
