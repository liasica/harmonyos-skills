可以按照以下方式启动调试会话。

1. 如果需要设置断点调试，找到需要暂停的代码片段，单击该代码行的左侧边栏。设置断点后，调试能够在正确的断点处中断，并高亮显示该行。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9d/v3/EUuEJX-EQsa2VbxmMUS3vQ/zh-cn_image_0000002779608673.png)
2. 在设备选择框中，选择调试的设备。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1f/v3/5hMkJP3NSPGNS2XYq1w_pQ/zh-cn_image_0000002750169650.png)
3. 选择启动调试的配置，在模块选择框中选择需要调试的模块。也可以[配置调试参数](ide-hmos-run-debug-configurations.md)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ae/v3/ZEWq_ROiR_OFcX0UFwswnw/zh-cn_image_0000002779608675.png)
4. 在工具栏中，单击调试 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/41/v3/fxGj3Uq8QPShWOMPS28RLg/zh-cn_image_0000002750009764.png)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f4/v3/CU6DT8K6RUekaZGizpKSnQ/zh-cn_image_0000002750009762.png)
5. 启动调试后，开发者可以通过[调试器](ide-hmos-debug-arkts-debugger.md)进行代码调试。

   如有断点会在断点处高亮，并展示当前断点处的帧和变量。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dc/v3/elD2h63LSOe4DixLZfqxHQ/zh-cn_image_0000002750169652.png)
