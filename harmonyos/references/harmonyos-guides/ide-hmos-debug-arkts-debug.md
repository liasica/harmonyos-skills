可以按照以下方式启动调试会话。

1. 如果需要设置断点调试，找到需要暂停的代码片段，单击该代码行的左侧边栏。设置断点后，调试能够在正确的断点处中断，并高亮显示该行。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b0/v3/7SQ-XN8LSa6tJGTAdCWFGQ/zh-cn_image_0000002781471130.png)
2. 在设备选择框中，选择调试的设备。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1d/v3/bdvGjbKhT3uSjG16_Ilgvg/zh-cn_image_0000002781311198.png)
3. 选择启动调试的配置，在模块选择框中选择需要调试的模块。也可以[配置调试参数](ide-hmos-run-debug-configurations.md)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d5/v3/KrsXbTlIRbie1IFAX3z-jw/zh-cn_image_0000002810630685.png)
4. 在工具栏中，单击调试 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/45/v3/4zQ0_rp-SQyu1sVrz-XYsw/zh-cn_image_0000002810630687.png)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/bd/v3/26282QZ6TFO4Virhbs6hBw/zh-cn_image_0000002810750791.png)
5. 启动调试后，开发者可以通过[调试器](ide-hmos-debug-arkts-debugger.md)进行代码调试。

   如有断点会在断点处高亮，并展示当前断点处的帧和变量。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0a/v3/B3UFguERSmC61svaQTRpOA/zh-cn_image_0000002781471134.png)
