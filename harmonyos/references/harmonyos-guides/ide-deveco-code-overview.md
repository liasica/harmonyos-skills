DevEco Code是面向HarmonyOS应用开发的一站式AI开发工具，基于华为[BitFun](https://www.openbitfun.com/)技术与开源OpenCode构建，集成HarmonyOS精品Skills、DevEco Studio开发工具链及HarmonyOS知识库，覆盖代码编写、编译构建、运行调试、ArkTS问题修复、开发文档查阅等全流程开发能力。

DevEco Code提供终端用户界面（Terminal User Interface，TUI）和DevEco Code Plugin可视化界面两种交互形态，开发者可根据场景选用：

* **DevEco Code TUI**：完整保留OpenCode的终端对话及Model、Provider、MCP、Skill配置能力，无需启动DevEco Studio，即可直接进行对话式开发与调试。
* **DevEco Code Plugin**：需先在DevEco Studio中打开代码工程，提供可视化操作与配置能力，可在开发、调试环节与DevEco Studio深度协同。
