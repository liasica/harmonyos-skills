DevEco Code插件具备自然语言生成代码能力，在**对话框内**输入代码需求描述后，Agent将自动理解意图、检索代码上下文、生成符合ArkTS规范的代码，并通过静态语法检查、编译构建、设备运行等环节，验证生成代码的准确性。

## 操作步骤

1. 选择适合场景的Agent模式。Build、Goal和Plan的具体介绍请参考[Agent模式](ide-deveco-code-agent.md)。鸿蒙电脑版DevEco Code不支持Ask模式。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/55/v3/ehosMIFRQ3SkO-I0lFjBLA/zh-cn_image_0000002783643344.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=01CA6CE4D391E3CF87FDDBAD6203BBE3FA3C0489AA989F0967AFBECD67ED1DFA)
2. 在对话框中输入功能需求描述，按Enter键或者点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/69/v3/KM5g1RH-Qk-q09XW5v9kaw/zh-cn_image_0000002779406676.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=FC0052C1EA1936AA161481FC98B0DAB768673936B885E8504A89126233520D40)发送。
3. 等待Agent自主执行，编辑或创建代码文件、检视代码上下文、执行ArkTS静态语法检查、编译构建等步骤。
