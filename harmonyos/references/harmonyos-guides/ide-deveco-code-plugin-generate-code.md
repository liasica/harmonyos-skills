DevEco Code插件具备自然语言生成代码能力，在**对话框内**输入代码需求描述后，Agent将自动理解意图、检索代码上下文、生成符合ArkTS规范的代码，并通过静态语法检查、编译构建、设备运行等环节，验证生成代码的准确性。

## 操作步骤

1. 选择适合场景的Agent模式。Build、Goal和Plan的具体介绍请参考[Agent模式](ide-deveco-code-agent.md)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d1/v3/GWX88z1hQLmTq4C8d677EA/zh-cn_image_0000002783643344.png?HW-CC-KV=V1&HW-CC-Date=20261114T004922Z&HW-CC-Expire=31536000000&HW-CC-Sign=B046FD1EA7510128C58B70A3E1F1B153441D32E15DB1380E6D4D2FD271B48DE3)
2. 在对话框中输入功能需求描述，按Enter键或者点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f3/v3/Xwy309iLQlaon7vDTwCloQ/zh-cn_image_0000002779406676.png?HW-CC-KV=V1&HW-CC-Date=20261114T004922Z&HW-CC-Expire=31536000000&HW-CC-Sign=05E5C8D970933BE5182CAD15C7FC03B3A903E4FDCC9F5FEB3811DC6989BA65D6)发送。
3. 等待Agent自主执行，编辑或创建代码文件、检视代码上下文、执行ArkTS静态语法检查、编译构建等步骤。
