DevEco Code插件具备自然语言生成代码能力，在**对话框内**输入代码需求描述后，Agent将自动理解意图、检索代码上下文、生成符合ArkTS规范的代码，并通过静态语法检查、编译构建、设备运行等环节，验证生成代码的准确性。

## 操作步骤

1. 选择适合场景的Agent模式。Build、Goal和Plan的具体介绍请参考[Agent模式](ide-deveco-code-agent.md)。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/98/v3/5Ita2mGUQsOrbhSgHxmGBg/zh-cn_image_0000002783643344.png)
2. 在对话框中输入功能需求描述，按Enter键或者点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/72/v3/dXi8oEXoSXi7N-sW-Ee1_g/zh-cn_image_0000002779406676.png)发送。
3. 等待Agent自主执行，编辑或创建代码文件、检视代码上下文、执行ArkTS静态语法检查、编译构建等步骤。

## 示例

在index页面中添加一个可以跳转至另外页面的按钮。
