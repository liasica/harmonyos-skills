## 环境准备（Windows/macOS）

1. DevEco Studio版本要求：DevEco Studio 6.0.0、DevEco Studio 6.0.1、DevEco Studio 6.0.2、DevEco Studio 6.1.0、DevEco Studio 6.1.1、DevEco Studio 26.0.0 Beta2及以上版本。
2. DevEco Code插件依赖CodeGenie，需要在DevEco Studio菜单栏点击**File > Settings**（macOS为**DevEco Studio > Preferences/Settings**）**> Plugins**，搜索和启用CodeGenie插件。CodeGenie插件默认已启用。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/92/v3/ZjcHdhykSJ-D6lS0kdu38g/zh-cn_image_0000002808766603.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=0DCC3D838BAC38AF3919D9B48E05FC47B1E4B8D1C4C9E8CDA500F89F15D3CDA9)

**说明** 

鸿蒙电脑版DevEco Code无需环境准备，一键安装即可。

## 安装和更新

### 一键安装

1. 在DevEco Studio左侧边栏点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ef/v3/-jAtOf0-Q-6Vme-nHYGePw/zh-cn_image_0000002808766607.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=4C01FCCAA2192CFDA972A78D7C33CA1BFD28082C18831248BD514734ACC23959)图标，打开DevEco Code**。**
2. 点击**Install Now**安装DevEco Code插件。若未登录请先点击**Sign in**，在华为账号登录页面完成登录。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a6/v3/-_AlGxXiTWeNi5nQIpV39A/zh-cn_image_0000002821941261.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=2F5B423C40DFDAAA0DEF19E0F76CA96BCABF8DB1B7869CF0A70787DCFC13D750)
3. 点击**Installation complete.Restart IDE.**，重启DevEco Studio后开始使用。

**说明** 

* 若Windows/macOS版DevEco Studio的左侧边栏未出现![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a5/v3/TCeufPChRi2SuxD5JV8Iiw/zh-cn_image_0000002793261316.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=F7765DBA7B06A9D2CEDCDB45C96828C71B1B229EB335EFE4F4C93331D6419E71)图标，需先点击弹窗中的**立即更新**，升级CodeGenie版本后，再安装DevEco Code插件。
* 鸿蒙电脑版DevEco Code插件安装后，无需重启DevEco Studio，即可开始使用。

### 本地安装

鸿蒙电脑版DevEco Code不支持该功能。

可通过[下载中心](https://developer.huawei.com/consumer/cn/download/deveco-code)获取最新的DevEco Code插件版本，并根据下载中心页面**工具完整性**指导进行完整性校验。插件安装包的存放路径不能包含中文字符。

DevEco Code插件版本需与DevEco Studio版本相匹配，具体对应关系如下：

* DevEco Studio 6.0.0、DevEco Studio 6.0.1、DevEco Studio 6.0.2、DevEco Studio 6.1.0、DevEco Studio 6.1.1支持安装DevEco Code Plugin 6.1.1 Release版本。
* DevEco Studio 26.0.0 Beta2及以上版本支持安装DevEco Code Plugin 26.0.1 Beta1及以上版本。

下载完成后，插件安装包无需解压，依照下方步骤进行安装：

1. 在DevEco Studio菜单栏，点击**File > Settings**（macOS为**DevEco Studio > Preferences****/****Settings**）**> Plugins**，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/16/v3/ruCBP3ZgRCSr0Y4dO8JM8g/zh-cn_image_0000002779407052.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=C96A8438C0A81A5FBAD5BCAD6491DB2D00AAAE976C2E695B0C9A2F495912BCB8) **> Install Plugin from Disk…**安装本地插件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/75/v3/4wEEL8F0QqWvGHckB3ff4w/zh-cn_image_0000002779567022.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=F458FBE59D40BC19DD3161B627AD69EF7443C2BECFD920A8F96234777896995A)
2. 在弹出的文件选择窗口中，选择**未解压的插件****包**的存放位置，点击**OK**确认安装插件。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f7/v3/NgF5_qmIRNWUZkQi5Che4g/zh-cn_image_0000002808766597.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=68B41E20647D8FD90F1CC3F5E781686C4233C37BFE3019868E15ED77A2126F74)
3. 在DevEco Studio左侧边栏点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/20/v3/rNlZjkPmT9OjtOpIKmmeWA/zh-cn_image_0000002808886693.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=3DCB8BF2E0A163F141B159CA44028D91E268788045F0B1D7A11D6D6CEF65166D)图标，登录后开始体验DevEco Code。

### 更新

鸿蒙电脑版DevEco Code不支持该功能。

进入**File > Settings**（macOS为**DevEco Studio > Preferences/Settings**） **> CodeGenie****> General**页面，勾选**Auto Update**，可以自动升级插件配置。

开启自动升级后，若管理台配置的插件可以静默升级，且系统检测到插件需要更新时，插件会自动升级；若管理台配置的插件不支持静默升级，会有弹框提示用户手动升级。未开启自动升级，也会有弹框提示用户手动升级。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/80/v3/I5JFkWQ_R0ei1ORtBtL78w/zh-cn_image_0000002808766615.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=30E562128B6546495683D831349D0965AEF22625F9AE0F195A0A765731E2B248)

## 会话管理

* **新建会话**：点击顶部**New Conversation**，即可创建新会话。
* **重命名会话**：在会话标题上右键，点击**Rename**，即可输入新的会话名称。
* **收藏****会话**：在会话标题上右键，点击**Favorite**，即可收藏或者取消收藏。
* **归档****会话**：在会话标题上右键 ，点击**Archive**，即可归档。鸿蒙电脑版DevEco Code不支持该功能。
* **删除****会话**：在会话标题上点删除图标（鸿蒙电脑版DevEco Code为在会话标题上右键点击**Delete**），即可以删除会话。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/9e/v3/_EfDhZm7StmIkcCk8xm5xQ/zh-cn_image_0000002793101334.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=EE79097DA7720481FC650706EB3EBF8F844CDAD597312BACDF05BD2F67687074 "点击放大")

## 会话交互

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b4/v3/sJkl4WWRS2Ko_YXY1s1oqQ/zh-cn_image_0000002783548358.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=761F6684ABE1CAC36737133168840EA96111498FD927308A71F61FCE2F51B328 "点击放大")

* **发送消息**：在输入框需求描述，按**Enter**或点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8c/v3/Iwep1W2iTwKN7Pik0JFFvQ/zh-cn_image_0000002779407042.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=0C6AE80A0280E5370D041516F7339E68CC3FD4B96CDAC673A9CB324BED143563)按钮发送后，等待回复。
* **停止生成**：内容生成过程中，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d1/v3/9rfHy-rRSIuqTSxMj3tNHA/zh-cn_image_0000002808886695.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=9FEA24A5EE151F715963F5E726E550A7332B6F9CC5E4DDB155A50D66501AB8B0)按钮，即可停止生成。
* **查看历史输入对话**：输入框为空时，通过键盘上/下方向键可浏览已发送的会话，包括附件和文件引用。
* **添加上下文：**为会话添加上下文帮助工具更准确地理解开发者需求，可通过如下方式添加：

  + 方式一：在输入框中输入**@**符号，在弹出的项目文件搜索列表中选择所需文件，所选文件以标签形式显示在输入框上方（如@index.d.ts），问答时将自动读取所选文件内容。

    ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b1/v3/bgnbYeTOQz6bXr7mOX1QNQ/zh-cn_image_0000002812947819.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=3C5DC48395A797535C85BACB52790C03B4417862262EF71EF87E7D57DCD6B3A5)

## 模型切换

点击底部输入框的模型名称下拉框，即可切换模型；在搜索框输入模型名称快速过滤模型；点击**Add model**配置更多模型，配置模型具体请参考[配置Models](ide-deveco-code-plugin-models.md)。鸿蒙电脑版DevEco Code不支持模型搜索功能。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5f/v3/hzLyjg-VQqSoYokArH7LPw/zh-cn_image_0000002779567028.png?HW-CC-KV=V1&HW-CC-Date=20261124T044251Z&HW-CC-Expire=31536000000&HW-CC-Sign=BE6960E5C25749F605F5DD66E33F219D61993245559D3EF418963E03DF7396C5)

## Agent模式切换

在底部输入框点击**Build**后的下拉框，可切换不同Agent模式。Agent模式介绍请参考[Agent模式](ide-deveco-code-agent.md)。

鸿蒙电脑版DevEco Code不支持Ask模式。
