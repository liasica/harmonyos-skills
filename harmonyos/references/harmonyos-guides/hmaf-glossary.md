## A

### Agent；智能体

一种能够自主执行任务、提供智能服务的应用组件。

### Agent to Agent (A2A)；智能体间通信协议

用于智能体（Agent）之间的通信。A2A Client端负责与Agent建立连接、发送任务请求、接收任务响应和查询任务状态；A2A Server端负责接收客户端请求、触发智能体执行任务、更新任务状态和返回执行结果。

### Agent Card；智能体卡片

Agent的元数据描述文档，用于描述智能体的信息，包含智能体的身份信息、能力描述、技能列表等。

### Artifact；智能体产物

智能体在任务执行生命周期中生成的不可变、可标识的交付物。与通用消息不同，智能体产物具有唯一的产物ID和人类可读的名称，可被独立引用和存储。产物可以是任务执行过程中的中间产物，也可以是最终成果。
