## A

### Asynchronous Connection-Oriented Bidirectional (ACB)；面向连接的异步双向链路

星闪技术中的一种异步双向数据传输链路，用于在设备间可靠地传输数据。

## C

### Client Property Configuration Descriptor (CPCD)；客户端属性值配置描述符

属性描述符的一种，定义了特定客户端如何配置属性值。

### Coordinated Devices Set Management (CDSM)；合作设备集合管理

对合作设备集合的管理。合作设备集合是由一组合作设备成员组成的、提供特定服务的统一整体。

## S

### SparkLink Service Access Protocol (SSAP)；星闪服务交互协议

定义了服务结构的发现过程和访问过程，以及过程中需要使用的信令。通过服务管理，星闪设备之间能够实现服务层面的互联互通。
