CodeGenie支持在**对话框中**输入对代码段和代码文件分析要求，帮助开发者快速理解代码逻辑、代码功能、技术细节和潜在问题等，提升开发效率。

DevEco Studio 6.0.2 Beta1之前版本，分析代码文件时需要通过**Files**入口选中文件；分析代码片段时，选中代码段后需点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/71/v3/rApcyWmNTyKK087178pt3w/zh-cn_image_0000002779406464.png?HW-CC-KV=V1&HW-CC-Date=20261114T004720Z&HW-CC-Expire=31536000000&HW-CC-Sign=3356B5337406E2E40F150B31C8BA93A181CDC40B79A8EADF4689EE7A5AD2C101)图标开启光标上下文功能。

在DevEco Studio 6.0.2 Beta1版本，分析代码文件时，支持在对话框输入要分析的代码文件或直接分析当前文件；分析代码片段时，选中代码段后直接分析，无需开启![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/57/v3/cfPys4HkT3irEYKJ_33FLQ/zh-cn_image_0000002808766019.png?HW-CC-KV=V1&HW-CC-Date=20261114T004720Z&HW-CC-Expire=31536000000&HW-CC-Sign=DDBA184F9869DB650B6836E119DC63845A860C825138728A90975E5CB8B1892D)图标。

从DevEco Studio 6.0.2 Release版本开始，使用HarmonyOS Ask智能体分析代码文件。

1. 选择HarmonyOS Ask智能体，在对话框中输入“**/**”，点击**Project**。
2. 在对话框输入**@**符号选择**Files**，或点击**@****Add Context** > **Files**，或在对话框输入文件路径，指定需要分析的代码文件。未指定代码文件时，分析当前代码文件。
3. 在对话框输入描述，点击![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a7/v3/2Wl9_KxASiap_XbUxs9Pzw/zh-cn_image_0000002808886101.png?HW-CC-KV=V1&HW-CC-Date=20261114T004720Z&HW-CC-Expire=31536000000&HW-CC-Sign=C3FA06622F1066FB6069F54D0ACCE446A122D4F167D255B4187158A18DF0826A)发送后等待回复。
