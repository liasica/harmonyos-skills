鸿蒙应用系统内存的使用原则：“前台精细化、后台极简化、销毁彻底化”。应用在前台时，可适当使用缓存提升性能，但也应避免前台峰值内存过大。应用退后台后，建议尽量释放内存（含缓存），实现后台内存最小化。应用须遵循系统生命周期的动态演进原则，确保在正确的节点执行正确的内存释放与恢复，避免在后台或前台非必要状态下维持高物理内存占用。

系统也具备低内存管控机制，如对用户弹窗低内存告警、对应用冻结甚至对应用进程进行查杀等措施，以保障系统和应用的韧性运行。
