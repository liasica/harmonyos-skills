智能填充将从华为账号、剪贴板、最近日程、联系人、历史表单输入和小艺帮记获取数据，以提供填充建议。

| 名称 | 说明 |
| --- | --- |
| 数据源推荐优先级 | 多输入框场景数据源推荐优先级：剪贴板>历史表单输入>华为账号>联系人>小艺帮记。  单输入框场景数据源推荐优先级：剪贴板>日程>华为账号。 |

**说明** 

上述优先级为默认推荐排序。智能填充在匹配推荐时会根据数据匹配度从高到低进行排序（剪贴板数据源优先级始终是最高的）。

## 填充数据源推荐方式说明

| 数据源 | 是否主动推荐 | 是否匹配推荐 |
| --- | --- | --- |
| 华为账号 | 是 | 是 |
| 联系人 | 否 | 是 |
| 日程 | 是 | 否 |
| 剪贴板 | 是 | 是 |
| 历史表单输入 | 否（车牌号/护照场景支持主动推荐） | 是 |
| 小艺帮记 | 是 | 是 |

**说明** 

* 剪贴板数据源推荐场景目前仅支持中文姓名和中文地址。
* 从HarmonyOS 7.0.0.109开始，新增小艺帮记数据源，支持在Phone设备中使用小艺帮记数据源进行填充，且仅支持通过导航条拉起智能填充的方式使用小艺帮记数据源进行填充，详见[智能识别模式下通过导航条拉起智能填充进行填充推荐场景](scenario-fusion-introduction-to-smart-fill.md#智能识别模式下通过导航条拉起智能填充进行填充推荐场景)。
* 若使用导航条拉起智能填充的方式进行数据推荐，则支持主动推荐来自历史表单输入的数据。

### 主动推荐与匹配推荐区别

| 名称 | 说明 |
| --- | --- |
| 主动推荐 | 1. 点击输入组件时，智能填充将主动提供填充建议。  2. 最多展示2条推荐数据。 |
| 匹配推荐 | 1. 根据输入组件中已经输入的字符进行数据源匹配，智能填充将匹配到的数据提供填充建议。  2. 最多展示3条推荐数据。 |

**说明** 

若通过导航条拉起智能填充进行数据推荐，则最多展示20条推荐数据。

## 部分场景数据推荐来源说明

| 名称 | 说明 |
| --- | --- |
| 地址单输入框场景 | 只推荐来自剪贴板和日程的地点信息。 |
| 昵称单输入框场景 | 只推荐华为账号的昵称。 |
| 车牌号单输入框场景 | 只推荐历史表单信息和华为账号的车牌号信息，仅支持主动推荐。 |
| 身份证号推荐逻辑 | 若设备未设置锁屏密码，不会推荐来自华为账号、历史表单输入和小艺帮记的身份证信息。当用户主动复制的情况下，仍可推荐来自剪贴板的身份证信息。 |
| 护照信息推荐逻辑 | 推荐来自历史表单输入和小艺帮记的信息，当前仅支持“中文姓名”及“拼音姓+名”的推荐。若设备无锁屏密码或华为账号未登录/未实名，则不推荐填充。若通过点击输入组件的方式推荐来自历史表单输入的数据，主动推荐限于机主本人信息（机主本人信息与登录账号实名姓名一致，判断账号实名需要打开华为账号数据源开关）；而匹配推荐则支持拼音姓加名的推荐。 |
| 设备登录不同类型的华为账号场景 | 设备登录国内成人账号时，支持剪贴板、日程、联系人、华为账号、历史表单输入、小艺帮记数据源；其他情况只支持剪贴板、日程和联系人数据源。 |
