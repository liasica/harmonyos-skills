## 运行环境要求

为保证鸿蒙电脑DevEco Studio正常运行，建议电脑配置满足如下要求：

* 操作系统：HarmonyOS 7.0及以上
* 设备型号：MateBook Pro、MateBook Fold 非凡大师、HUAWEI MateBook 14 鸿蒙版、HUAWEI MateBook Fold 非凡大师 麒麟X90、MateBook Pro S、MatePad Edge
* 内存：16 GB及以上
* 硬盘：100 GB及以上
* 分辨率：1280\*800像素及以上

## 下载与安装

1. 打开**应用市场**，点击**我的** **>** **应用尝鲜**，查找DevEco Studio点击**安装**按钮。

   ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c4/v3/ddWwuV7zRrarslbff4SySQ/zh-cn_image_0000002781470982.png "点击放大")
2. 点击鸿蒙电脑左下角**应用中心**，出现如下图标即为安装成功。
