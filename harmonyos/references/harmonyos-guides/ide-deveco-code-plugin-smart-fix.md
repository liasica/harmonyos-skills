应用工程构建过程中，如果出现ArkTS语法相关的编译报错，DevEco Code会提供AI自动修复能力。

点击报错信息后方**Quick Fix**，DevEco Code将自动引用构建报错信息，并自动修复代码源文件。

![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ec/v3/QnznjsUbRfy_QJ8AqF0URA/zh-cn_image_0000002783483060.png?HW-CC-KV=V1&HW-CC-Date=20261114T004922Z&HW-CC-Expire=31536000000&HW-CC-Sign=B2425A370BC43E8A4F19B71FF801D881A7DC08A1AD1100A8B0B4B520C7CE4FAD "点击放大")

如需关闭编译报错智能分析和自动修复，进入**File > Settings**（macOS为**DevEco Studio > Preferences/Settings**） **> CodeGenie****> General**页面，取消勾选**Enable AI auto-fix for build errors**。
