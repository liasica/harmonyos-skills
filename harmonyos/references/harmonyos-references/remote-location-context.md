RemoteLocationExtensionContext是[RemoteLocationExtensionAbility](remote-location-ability.md)的上下文环境，继承自[ExtensionContext](js-apis-inner-application-extensioncontext.md)，未新增内容。RemoteLocationExtensionContext模块提供访问RemoteLocationExtensionAbility资源的能力。

**模型约束：** 属性仅可在Stage模型下使用。

**系统能力：** SystemCapability.Push.PushService

**起始版本：** 4.1.0(11)

## 导入模块

```typescript
import { RemoteLocationExtensionContext } from '@kit.PushKit';
```
