## 概述

此结构体描述OpenGTX三维向量。

**起始版本：** 5.0.0(12)

**相关模块：** [GraphicsAccelerate](_graphics_accelerate.md)

**所在头文件：** [opengtx\_base.h](opengtx__base_8h.md)

## 汇总

### 成员变量

| 名称 | 描述 |
| --- | --- |
| float [x](_open_g_t_x___vector3.md#x) | 三维向量的X轴数据。  取值范围：[-360, 360]。 |
| float [y](_open_g_t_x___vector3.md#y) | 三维向量的Y轴数据。  取值范围：[-360, 360]。 |
| float [z](_open_g_t_x___vector3.md#z) | 三维向量的Z轴数据。  取值范围：[-360, 360]。 |
