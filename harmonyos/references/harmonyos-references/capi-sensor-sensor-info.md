```c
typedef struct Sensor_Info Sensor_Info
```

## 概述

定义传感器信息结构体，用于存储传感器的基本属性和数据信息，包括传感器类型、版本、标识等关键字段。开发者通过该结构体可获取传感器的完整描述信息，用于传感器的初始化和数据查询。

**起始版本：** 11

**相关模块：** [Sensor](capi-sensor.md)

**所在头文件：** [oh\_sensor\_type.h](capi-oh-sensor-type-h.md)
